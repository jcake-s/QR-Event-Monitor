# QR-Event-Monitor

The QR Event Monitor system is a lightweight, high-performance web dashboard designed for event coordinators to streamline guest check-ins, attendance tracking, and capacity management in real time.

Featuring a modern glassmorphism interface with ambient background visuals, the application pairs camera-based QR code scanning with client-side state management providing immediate feedback on guest status without requiring an active backend server or database connection.

# KEY Capabilities and Features

- Live QR code Scanning

- Dynamic State and Action Tracking

- Real-Time Metrics and Directory

- Client-side Persistence and Data Controls
